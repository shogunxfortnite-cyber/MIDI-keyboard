# MIDI-keyboard
A mini midi keyboard


## What i used
I used KICAD for making the overall schematic and pcb. 

For code we can either use a python script or c++(arduino ide) .

## How to make 
Check out https://github.com/KaiPereira/MIDI-Keypad/blob/master/README.md to see the step by step process.

You can either edit this or directly download it from my repo.

My repo has both the ino and py script.
